របៀបប្រើ

  1. ដំឡើង ViGEmBus លើ PC (ម្តងគត់) · ទូរស័ព្ទបើក USB debugging ហើយភ្ជាប់ខ្សែ USB។
  2. ចុច Refresh ជ្រើសទូរស័ព្ទ រួចចុច Connect។
  3. បើក app Phone Controller លើទូរស័ព្ទ (ឬចុច Open app on phone)។ ពេល App ឆ្លុះបៃតង គឺរួចរាល់។
  4. ជ្រើស mode លើទូរស័ព្ទ៖ Gamepad (Roblox / Bedrock / ហ្គេម controller), Minecraft Java, Roblox KB+Mouse, Touchpad ឬ Racing (ងាកទូរស័ព្ទជាកង់ចង្កូត សម្រាប់ហ្គេមឡាន)។
  5. ប៊ូតុង KEYS លើទូរស័ព្ទ = វាយអក្សរ (ខ្មែរបាន), Ctrl/Shift/Alt, Paste។ GYRO = ងាកទូរស័ព្ទដើម្បីបង្វិលកាមេរ៉ា។ MOUSE ON = stick ស្តាំជា cursor ក្នុង Gamepad mode។

បញ្ហាញឹកញាប់

  • App: waiting → ពិនិត្យ Console, ចុច Restart ADB, ឬដោត USB ឡើងវិញ។
  • ហ្គេមរត់ជា Administrator → ត្រូវរត់ app នេះជា Administrator ដែរ។
  • ViGEmBus error → ដំឡើង driver រួច restart app។
